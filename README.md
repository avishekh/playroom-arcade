# Playroom Arcade

Learning games for kids: Count It, Add & Take, Letter Hunt, What's Next?, Tell Time, Memory Match and Space Blaster. Each game levels up as the player wins rounds. Progress is saved in the browser.

Play: https://avishekh.github.io/playroom-arcade/

## Action Arcade (ages 9+)

Eight games in `action/` with a dark sci-fi look, lighting and hit effects: Last Keep (tower defense), Garden Siege (lane defense), Void Strike (shooter), Orbital Defense (blaster), Storm Runner (flying), Mech Arena (fighting), Block Forge (building) and Drone Code (block coding). Works with touch, mouse or keyboard. Best scores and the Block Forge world are saved in the browser.

Play: https://avishekh.github.io/playroom-arcade/action/
