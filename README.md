# Playroom Arcade

Learning games for kids: Count It, Add & Take, Letter Hunt, What's Next?, Tell Time, Memory Match and Space Blaster. Each game levels up as the player wins rounds. Progress is saved in the browser.

Play: https://avishekh.github.io/playroom-arcade/

## Action Arcade (ages 9+)

Ten games in `action/` with a dark sci-fi look, lighting and hit effects: Neon Stack (falling-block puzzle), Viper Grid (snake), Last Keep (12-level tower defense campaign across four lands, eight tower types), Garden Siege (lane defense), Void Strike (shooter), Orbital Defense (blaster), Storm Runner (flying), Mech Arena (fighting), Block Forge (building) and Drone Code (block coding). Works with touch, mouse or keyboard. Best scores and the Block Forge world are saved in the browser.

Play: https://avishekh.github.io/playroom-arcade/action/
